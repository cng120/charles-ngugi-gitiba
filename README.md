# Game Design Studio

A professional web-based game design tool for creating, visualizing, and prototyping game concepts.

## Features

- **Interactive Canvas**: Design game layouts with an 800x600 canvas featuring a customizable grid
- **Game Elements**: Place various game elements including:
  - 👤 Player characters
  - 👾 Enemies
  - 💰 Coins and collectibles
  - 🧱 Obstacles
  - ⭐ Power-ups
  - 🏁 Goals
- **Customization Options**:
  - Adjustable grid size (20-100 pixels)
  - Custom background colors
  - Multiple game genres (Action, Adventure, RPG, Puzzle, Strategy, Sports)
- **Save & Export**: Save designs to browser localStorage and export as JSON/PNG files
- **Design Gallery**: View, load, and manage all saved game designs

## Getting Started

1. Open `index.html` in a web browser
2. Navigate to the "Designer" section
3. Enter a game name and select a genre
4. Click on element buttons and then click on the canvas to place them
5. Customize the background color and grid size
6. Save your design or export it for further development

## Usage

- **Place Elements**: Select an element button, then click anywhere on the canvas to place it
- **Clear Canvas**: Remove all elements from the canvas
- **Save Design**: Store your game design in the browser's local storage
- **Export**: Download your design as JSON data and a PNG preview image
- **Load Design**: Retrieve previously saved designs from the gallery

## Technologies Used

- HTML5 Canvas for game visualization
- Modern CSS3 with gradients and animations
- Vanilla JavaScript for interactivity
- LocalStorage for data persistence

## Live Demo

Simply open the `index.html` file in any modern web browser to start designing games!
